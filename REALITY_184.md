# Reality 184 — Магазин влияния

Reality 184 расширяет существующего Telegram-бота «Главный герой» отдельным слоем. Старые механики, таблицы и команды не удаляются: новый entrypoint сначала устанавливает `talent_entry_v164`, затем подключает `hero_expansion_v184` последним слоем.

## Что добавлено

### Магазин влияния

Отдельная Telegram Mini App по адресу `/influence-shop-v184/`:

- профиль, роль, аура, титул, рамка и текущий баланс;
- категории «Популярное», «Статус», «Защита», «Хаос», «Внешний вид»;
- серверная повторная проверка баланса;
- уникальный `request_id` и защита от повторной покупки;
- обновление баланса без перезагрузки;
- Telegram Haptic Feedback;
- анимации карточек, покупки, частиц, графиков и достижений;
- адаптация под мобильный экран и `prefers-reduced-motion`.

### Единая история влияния

`change_influence` выполняет изменение внутри `BEGIN IMMEDIATE`, блокирует отрицательный баланс, сохраняет баланс до и после, причину, тип операции и уникальный ID. Повторная операция с тем же ID возвращает прежний результат без нового списания.

Старый `Database.add_points` обёрнут зеркалом, поэтому существующие начисления продолжают работать и одновременно попадают в новую историю операций.

### Сюжет беседы

- таблица сюжетных событий;
- фиксация покупок, саботажей, импичментов, побед над боссом, достижений и возвращений;
- временная шкала в Mini App;
- фильтры по важности и участнику;
- еженедельная фактическая хроника без выдуманных событий.

### Отношения участников

Хранятся близость, доверие, соперничество и хаос. Ответы и реакции меняют отношения с дневным лимитом, чтобы связи нельзя было накрутить спамом. Mini App показывает карту связей и подробный список пар.

### Тайные достижения

Добавлено 27 достижений пяти редкостей. До открытия условие скрыто. Повторно выдать одно достижение невозможно. Награды могут содержать влияние, титул, рамку, эффект или коллекционный значок.

### Возвращение неактивных

Фоновая проверка ищет ранее активного участника, который не писал не менее 14 дней. Событие длится 2 часа, имеет кулдаун 3 дня на беседу и 30 дней на участника. Возвращение награждается один раз, призвавшие делят дополнительный фонд.

### Статистика

Mini App показывает:

- динамику влияния за 7, 30 и 90 дней;
- начисления, списания и покупки;
- место в рейтинге;
- победы, поражения и серии;
- вмешательства;
- сообщения и активность;
- отношения, сюжет и достижения.

### «Вмешаться»

После подтверждённого успешного вмешательства сервер случайно списывает от 1 000 до 5 000 влияния. Стоимость рассчитывается только на сервере и записывается с причиной `intervention_cost`. Уникальный ID попытки не допускает повторного списания.

## Новые команды

- `/shop` — открыть магазин;
- `/hero` или `/menu` — компактное меню;
- `/stats` — краткая статистика;
- `/story` — последние события сюжета;
- `/achievements` — открытые достижения;
- `/relationships` — игровые связи.

## Миграции

Миграции выполняются автоматически после штатного `Database.connect`. Используется `CREATE TABLE IF NOT EXISTS`, существующие таблицы и данные не удаляются.

Основные новые сущности:

- `influence_transactions`;
- `shop_items`, `shop_purchases`, `user_inventory`, `user_effects`;
- `story_events`, `weekly_story_reports`;
- `user_relationships`, `relationship_daily`;
- `achievement_definitions`, `user_achievements`, `achievement_progress`;
- `inactive_return_events`, `inactive_return_callers`;
- `user_daily_statistics`, `user_chat_statistics`, `chat_statistics`;
- `profile_frames`, `user_profile_customization`.

## Установка и запуск

Новых Python-зависимостей нет. Используются зависимости существующего проекта.

```bash
pip install -r requirements.txt
python talent_entry_v184.py
```

Amvera уже переключена на `talent_entry_v184.py` в `amvera.yml`.

Для локального запуска Mini App должен быть настроен существующий публичный адрес:

```env
BOT_TOKEN=...
WEBAPP_PUBLIC_URL=https://example.com
BOT_PUBLIC_USERNAME=...
WEBAPP_SHORT_NAME=...
```

Новых обязательных переменных окружения Reality 184 не добавляет.

## Подключение Telegram Mini App

Reality 184 использует существующую схему запуска:

```text
https://t.me/<bot_username>/<short_name>?startapp=shop_<chat_id>
```

Если Telegram `startapp` не настроен, используется fallback через `WEBAPP_PUBLIC_URL/influence-shop-v184/?chat_id=<chat_id>`.

Авторизация API выполняется через существующий `_webapp_auth` и проверенный Telegram `initData`. Переданный фронтендом `user_id` не используется как источник доверия.

## Проверки

```bash
python -m py_compile hero_expansion_v184.py talent_entry_v184.py
node --check webapp/influence_shop_v184/app.js
python -m unittest -v tests/test_hero_expansion_v184.py
```

Проверяются миграции, цены, транзакции, недостаточный баланс, повторные и параллельные операции, диапазон стоимости вмешательства, фильтрация титула, лимит отношений, покупка, идемпотентность достижений, сюжет и разделение данных по чатам.

## Исходник серверного слоя

Из-за ограничения передачи большого файла через Contents API серверный модуль хранится в восьми Base85-фрагментах в `hero_v184_payload/`. `hero_expansion_v184.py` проверяет SHA-256 всего payload и распакованного исходника перед исполнением.

Для получения обычного читаемого файла:

```bash
python tools/unpack_hero_v184.py
```

Команда создаст `hero_expansion_v184_source.py` и также проверит контрольные суммы.
